# Haskell Self Study
Learning based on [Learn You a Haskell](https://learnyouahaskell.github.io/).

## Focusing on...
**Chapters 1-3:** Introduction, Starting Out (lists, tuples), and Types/Typeclasses  
**Chapters 4-5:** Syntax in Functions (pattern matching, guards, `let`/`where`) and Recursion  
**Chapters 6-7:** Higher Order Functions and Modules (`Data.List`, `Data.Map`, etc.)  
**Chapters 8-10:** Making Our Own Types, Input and Output (I/O), and Functionally Solving Problems  
**Chapters 11-14:** Functors, Applicative Functors, Monads, and Zippers
